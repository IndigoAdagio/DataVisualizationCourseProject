# Real-time-inspired Visual Analytics of Urban Air Quality in China (2022–2025)

This project is a multi-view visual analytics dashboard for Chinese urban air quality,
built with **Streamlit**, **Plotly**, and **Pandas**.

It supports:
- Overview dashboard with KPI cards
- Spatial distribution map
- Time-series comparison
- Pollutant composition (bar + radar)
- Data story view (automatic pollution episode detection)
- Forecasting view (simple baseline model)
- **New: Heatmap view** (spatial AQI / pollutant heatmap, station- and city-level)

A small sample dataset is included so the app can run out-of-the-box.
You can replace it with your own large-scale raw data.

## 2. Quickstart with sample data

1. Install dependencies (preferably in a virtual environment):

   ```bash
   pip install -r requirements.txt
   ```

2. Run the app:

   ```bash
   streamlit run app.py
   ```

   On the first run, if `data/processed/hourly.parquet` and `daily_city.parquet`
   do not exist yet, the app will automatically build them from the sample data
   under `data/sample_raw/` by calling the ingest pipeline.

## 3. Using your full raw data

1. Place your raw CSVs under:

   ```text
   data/raw/YYYY-MM-DD/YYYY-MM-DDTHH.csv
   ```

   The folder and filename pattern should match the sample data under `data/sample_raw/`.

2. From the project root, run:

   ```bash
   python -m src.ingest --use-raw
   ```

   This will:

   - scan all CSVs in `data/raw/`
   - merge them into a long station-hour table
   - run preprocessing and aggregations
   - write out two Parquet files under `data/processed/`

3. Start Streamlit (or restart if already running):

   ```bash
   streamlit run app.py
   ```

   The dashboard will now use your full dataset.

## 4. Heatmap view

The **Heatmap** tab provides an additional spatial analytics view:

- uses a geographic heatmap (Plotly `density_mapbox`)
- supports **station-level** and **city-level** aggregation
- fully respects global filters:
  - date range
  - pollutant selector
  - city and station selectors

No extra setup is required beyond the existing dependencies.
